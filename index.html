AI NATIVE ORGANIZATION v5

AI Native 组织整体规划

以 AI 为新的基础生产力，将公司重新封装为可自循环的 AI 决策组织

AI Native 不是简单给现有工作叠加AI工具，也不是由技术部门建设若干AI应用，而是以AI作为新的基础生产力，重新定义公司的经营逻辑、协作方式和管理模式。
AI Native 意味着将公司的知识、规则、标准、流程和人的判断，重新封装为可持续运行、持续更新、持续调用的组织Agent，使公司本身逐步演进为AI自循环决策组织，从而提升经营管理能力。

第一部分：组织形态重构

从「职能型组织」→「AI 驱动的敏捷型组织」

🏛️（一）重新定义组织：从「职能型组织」转向「AI驱动的敏捷型组织」▼

目标：AI Native的组织建设，就是通过不断优化人和AI的分工边界，让AI承担其擅长的工作（高频重复、规则明确和数据处理类），释放人的精力聚焦更高价值的判断和创造领域的探索上。当期重点推进：

📐
组织层级精简

进一步将组织数量层级减少，打破部门墙实现扁平化、敏捷化。让AI逐步取代组织本身所承担的协调功能，让组织内信息流转更快，对战略和业务需求响应更迅速。

⚔️
AI 场景小队/部落

围绕电销、客服、风控、营销、消保、资管、HR、财务等重点细分场景，分别建立跨部门AI场景小队+部落，由业务提出问题，AI和技术提供能力，风控、合规、消保、信息安全等部门前置把关，共同推动场景落地。

🏗️
AI 能力平台

建设公司级AI能力平台，将模型、数据、知识库、Agent工具、权限安全、评估监控等共性能力统一沉淀，形成公司级AI公共底座，为各类AI场景小队提供支撑。

🔁（二）重新定义岗位：从「界定人完成什么任务」转向「界定人机如何协同履职」▼
岗位的变革

AI原生化下，岗位及任职资格不再只是描述"人负责什么工作"，而是要重新界定人与AI的共同职责。机械重复类工作逐步交由AI承担；人的精力转向抽象和定义问题、设定边界、处理特殊情况、审定结果等。

岗位的重构

重新拟定现有岗位体系，逐步裁撤重复操纵类岗位。同时，利用AI对单人能力的放大，推动相近岗位适度融合，引导员工能从更完整的业务链条理解岗位工作，减少跨岗位协作的效率损失。

岗位的新增

基于AI原生生态下进行岗位缺位和能力补充，新增如：AI 应用架构师、Agent工程师、AI训练师（AIT）、AI 数据治理师、AI技术栈相关人才（数据库运维等）

• Code Review 不是找 Bug，而是审 Agent
• 新人入职指南里第一条是配好你的数字员工

第二部分：决策流程重构

从「经验驱动」→「AI 建议 + 人确定」

🤖（一）重新定义决策：从「经验驱动」转向「AI建议+人确定」▼

将AI纳入业务决策流程：在决策前，应由AI先完成信息汇总、方案比较、风险识别和关键问题汇总，再由管理者结合战略目标、业务现实和风险边界进行判断，真正实现让AI进入"辅助判断"。当期重点推进：

🩸
数据即血液

将业务数据、历史案例、管理规则、外部信息和专家经验等关键资料导入AI可调用的知识体系，并改造决策流程，建立完善的数据体系，从而实现业务数据化、追溯化。

🧠
公司模型（参考Block）

将战略层-经营层-运营层-执行层的能力接入AI，建立基于自身运营的"公司模型"，让其可以自动模拟-决策-优化，最终变成组织的默认能力。

🙋 公司模型 (参考Block)

公司理解自身运营、绩效和优先级的方式。Block公司过往所有决策、讨论、代码、设计、计划、问题和进展都以数字记录的形式存在。在传统公司，经理的工作是了解团队发生的一切，并把这种情境信息在指挥链中上下传递。而在AI公司，AI可以持续构建和维护这个全景图：正在构建什么、什么被阻塞了、资源分配到哪里、什么有效、什么无效。这就是层级过去承载的信息，现在由公司世界模型承载。

⚡（二）重新定义流程：AI Agent 感知 → 自动生成任务 → 推送/执行 → 人确认异常▼

AI Native流程：AI Agent感知环境变化 → 自动生成任务 → 推送给合适的人或自动执行 → 人仅需确认异常点。

类型旧流程AI Native 新流程
业务流程面向客户，创造核心产品/服务，产生营收AI提供市场模拟、压力测试数据、动态分配预算/排期/调价等，人做最终拍板。目标：服务增收、提效、提质和规模化增长。
管理流程员工登录系统 → 申请任务 → 等待审批 → 执行AI统筹、监督、规则管控来规范业务与辅助流程，保障组织有序运转。提升决策质量、透明度和风险控制能力。
辅助流程后勤支撑沉淀更多可调用的Skills和Agent推进流程进步和实现。降本、提效、少人化、标准化。
🙋 入职流程变革

过去：新员工入职第一天接到一堆飞书文档（组织架构图、流程手册、工具列表、培训视频）。
现在：给你一组可调用的 Skills 和 Agent，再给你一份"如何使用它们解决你岗位上常见任务"的指南。从"先理解再动手"切换成"先调用再理解"。

📋（三）重新定义制度：从「方便人阅读」转向「利于AI调用」▼
制度规则的定义

对制度中的规则要求、适用条件、操作步骤、审批节点、责任边界等内容进行标签化处理，使AI能够准确理解制度适用于什么场景、触发什么规则、需要执行什么动作、哪些情况必须人工复核等。

制度AI沉淀

围绕合同审核、客户投诉、采购管理等各具体业务场景，将分散在不同制度中的相关要求重新组合，封装为可调用的知识包或Skill。实际工作中，可通过AI直接调用相应能力，即刻获得制度依据、风险提示、执行建议等。

第四部分：文化导向重构

从「被动使用 AI」→「AI 优先的思维」→「AI 原生的心智」

🎯（一）文化理念与七大维度▼

秉承"源于AI、拥有AI、应用AI、开放AI"的文化理念，员工的核心贡献不再是"执行指令"，而是"快速定义并抽象问题，利用AI满足用户需求"。颠覆性创新将成为常态，要求人有终身学习的能力，长期在自己的岗位上利用AI积累能力和创造价值。从而推进AI从被使用的工具转变为核心生产力，形成"AI原生"的心智。

🔍 开放透明

信息透明，决策透明，协作透明，知识透明，反馈透明。AI原生生态下，让信息流动，让决策可见，让协作无边界。

💡 思辨能力

思辨能力不是"回答问题"，而是"提出更好的问题"。不盲从AI输出，敢于追问"数据来源是什么？""逻辑是否成立？""是否存在幸存者偏差？"，并对AI产出有价值判断。

📊 数据驱动

"数据即产品"与"全量全要素连接"。数据不是副产品，而是生产原料。强调数据的实时性、准确性及流转效率。打破数据孤岛，主张"谁使用数据，谁定义数据"，推崇DataOps文化。

🧪 实验精神

高频率的A/B测试与容忍失败。推崇"假设-验证-迭代"的极速循环。将失败视为模型训练的必要成本，鼓励灰度发布和在线实验。

🧑‍🎓 人才理念

"人机协作"与"T型人才"。不再单纯追求庞大的程序员队伍，而是看重"懂业务的AI应用者"。强调全员具备AI素养，将AI视为Copilot（副驾驶）。

🏗️ 组织架构

扁平化、流动性与中台化。打破严格的部门墙，采用跨职能的敏捷小队。构建强大的技术中台/AI中台，使前台业务可以像搭积木一样调用智能能力。

⚖️ AI伦理与治理

将公平性、可解释性与问责制嵌入AI全生命周期，从"先跑再治"转向"合规前置"。伦理治理不是事后补救的"安检卡口"，而是贯穿数据采集、模型训练、产品上线、持续运营全流程的"内建基因"。

🏆（二）从「执行者」→「主人翁」：敢想 · 会问 · 善学▼

敢想 — 主动识别AI可介入的业务痛点和管理难点
会问 — 围绕价值、可行性、合规安全持续追问
善学 — 复盘提炼推广，个人经验→团队方法→组织能力

落地规划

🙋 经营分析AI转型

以数据 + 模型 + 经验沉淀 + 流程重构为核心，构建企业级经营分析 AI 中台，覆盖日常日报、周会分析、风控/客户/贷后经营场景，逐步扩展到财务等其他领域；通过飞书实时通讯工具协同闭环，实现每日迭代、每周优化、持续沉淀能力。

场景1：每日复盘
早上直接看 Agent 生成的日报，快速掌握昨日经营全貌。异常指标直接标注，由业务+数据共同确认根因，同步优化 Agent 逻辑。业务新规则、新口径、新判断标准，由 AI 训练师沉淀为 Skill，次日自动生效。

场景2：周/月经营会议
Agent 提前 1 天自动生成周/月经营分析报告，会前全员飞阅会批注，会议时间压缩50%以上。会议聚焦：问题讨论、策略制定、资源协调、Agent 优化项确认。会后形成会议纪要，由 Agent 自动归档，作为后续分析参考。

  • AI原生变革路线图：定义自身关键问题和分阶段的关键里程碑、时间规划

任务二：开展各域数字员工专项

对于确定性高、流程清晰、风险敏感的领域，推动数字员工专项，实施组织级AI落地，整体以：业务定位场景 → 技术评估工具与平台 → 技术赋能业务实操 → 业务与技术共建数字员工 → 小队共训练 → 数字员工上岗一系列运营，实现"AI能力应用"向"高效人机协同组织"演进。

目标完成数字员工立项数量≥30个，完成数字员工上岗数量≥20个。

🙋 数字员工岗位定义

数字员工是指基于人工智能（AI）、机器人流程自动化（RPA）、大数据、自然语言处理（NLP）等技术开发的，能够模拟人类员工执行特定规则、流程或决策任务的软件机器人、智能体或虚拟助手。四要素：
• 可感知 — 有直接的用户交互渠道（chat，application）
• 可岗位化 — 有企业/社会同岗位定义参考，针对不同级别有不同能力要求
• 可完成具体任务 — 基于员工工作流程可替代性完成日常的、基础的、重复性的具体工作任务
• 可被管理 — 有能效、业务价值的显性指标管理，对工作流程有明确的输出贡献

🏢3. 管理层：围绕AI原生重构组织、岗位、人才、考核、文化机制▼
任务一：进一步精简组织层级
  • 组织：经过组织调整、合并同类项等，现马上四级、五级组织减少339个，整体降幅约47.3%，末尾组织减少占据90%。今年内计划精简为三层组织。
  • 层级：聚焦压缩仅做信息汇总、上传下达、进度催办等中间层。基于AI工具，初步实现组织层级不超过3层且保证日常运转更高效。
任务二：全面梳理岗位体系，推动低价值岗位转型
  • 逐步裁撤重复操作类职能岗位，并推动相关人员向AI协同岗、业务深耕岗、流程运营岗转型。
  • 引导管理岗从"管事、管流程、管进度"，转向"管AI流程、管数据质量、管人机协同、管结果责任"。
  • 引导技术岗从传统开发交付，转向AI应用开发、Agent编排、RAG搭建、模型调用和AI工程化运营。
🙋 Claw 智能风控助理

当前，公司风控团队承担着海量业务数据的日常监控、审批异动分析及模型效果评估分析等核心工作。现有分析工作模式大概分为两类：
1. 固定监控分析任务：基于飞书文档提出的业务需求，数据分析师需每日、每周执行大量标准化的审批监控、指标追踪及风险预警任务。此类任务具有高度重复性，涉及多系统数据提取、规则计算、结果汇总及飞书群通知等环节。
2. 临时性深度分析任务：例如针对模型效果分析评估、放款策略分析、逾期原因挖掘等非标准化需求，分析师通常使用分析主机上存储的Parquet宽表数据文件进行探索性分析，为策略优化提供数据支撑。
目前，团队已通过OpenClaw结合飞书机器人初步实现了上述两类任务的自动化与智能化处理，具备扎实的落地基础。该场景直接服务于风控决策核心环节，对提升风险识别效率、降低资产逾期率、释放分析师产能具有重要战略价值。

任务三：建成"业务数字+能力数字"的AI原生考核机制

以终为始：Token消耗量不等于AI价值创造，建立以业务结果为终点的AI原生过程性指标，匹配公司AI能力/数据平台建设、AI流程化改造、各岗位人机协同梳理等关键AI原生改革节奏。

任务四：基于AI原生生态下进行岗位缺位和能力补充，新增岗位并引入专业人才

新增如：AI应用架构师、Agent工程师、AI训练师（AIT）、AI数据治理师、AI技术栈相关人才（数据库运维等）。

任务五：人才盘点 — 重新定义人才，对分层人才能力进行重新定级
  • 360+AI模型：基于360°评估（M类）+客观数据+绩效，对现有干部进行分类分级评估，形成九宫格落位，明确每位干部在当前干部序列中的相对水平。基于AI Agent调优员工择优模型，纳入AI相关评价标准，在员工层面宣导AI转型的导向。
  • 引入新AI人才能力分层分级标准（A1-A4），推动员工能力全面升级：从传统"执行指令、解决问题"的执行型人才，转变为"定义问题、研判价值、统筹决策"的掌舵型人才。
任务六：重新塑造AI原生文化，基于战略调整开展文化体系重塑

基于AI原生组织转型的战略方向将文化价值观体系进行系统化更新，例如原"科技驱动的金融机构"更新为"AI原生的金融机构"。保留"诚信""团队""效率""创新""以用户为中心"的文化底蕴，并引入AI原生型组织的全新文化内涵"透明""开放""正直""数据驱动""独立思考""判断力"等，在2026下半年开展AI原生文化调研及内部共创。

🔄4. 决策与流程层：推动AI进入日常决策和流程运行▼

在材料生成、数据分析、会议纪要、制度问答、知识检索、经营分析等管理和辅助流程中接入AI，让AI参与信息汇总、方案比较和风险提示，提升日常运营效率。

任务一：AI辅助流程决策

在现有OA流程中在审批环节提供AI辅助决策能力，对流程风险进行标识和决策建议，目前已覆盖大约100个有制度支持的流程。其余流程需推动流程及规则完善，进而提供对应流程决策能力。

任务二：支持自定义、个性化决策规则经验沉淀

将流程授权、自定义决策、个性化决策能力封装为可复用Skill，支持决策人进行规则内的AI授权决策。

🙋 决策流程优化

在规则范围内的员工出差流程，基于流程风险识别，为绿色的可做AI授权自动审批。

任务三：以新的组织形态为目标，对各领域核心业务流程进行端到端的梳理与优化

全面开展制度、流程、授权等内容扫描，针对AI原生转型方向开展优化，对业务、管理、授权等制度流程有着根本性颠覆，需反观各域制度流程是否需要更新迭代，以适应甚至引领AI原生转型发展。

🙋 研发流程优化

传统研发流程为需求提出（需求文档）→ 产品设计（产品文档及原型）→ 研发上线（技术文档）→ 测试（测试用例），而基于AI原生生态下的研发流程可调整为需求提出（AI生成需求文档）→ AI产品原型设计 → AI coding demo生产及测试 → 交付研发进行真实环境复刻，极高提升研发效率。
